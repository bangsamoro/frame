How it works

Four moves, one screen.

01

Point it somewhere

Paste a URL, open a local HTML file, or drop in a screenshot. Nothing is uploaded — the studio is a static page and the image never leaves your machine.

02

Pick the frames

All six can be on stage at once — a 384-pixel phone and a 1600-pixel display, each rendering the page at its real viewport width. Toggle any frame with the number keys.

03

Check the layout, then compose

The live viewer renders the real page at each width. Switch to the mockup stage to place the page inside the frame and set how it sits in the screen: fit, background, chrome, shadow, scale.

04

Download or copy

PNG at 1×, 2× or 3×, transparent by default, straight onto the clipboard if you prefer. Download all selected frames in one pass.

Help

What it can and cannot do.

Can InstaFrame capture any live site by itself?

A browser cannot read the pixels of a cross-origin page — that is a security boundary, not a missing feature. So the workflow is split: the live viewer shows any page that allows embedding, and the export composes from a screenshot, which gives you a pixel-perfect result for any site, logged-in pages included.

Why does a live frame stay blank?

The site sent X-Frame-Options: DENY or a frame-ancestors rule that excludes other origins. Open it in a new tab from the frame caption, take a screenshot, and drop that into the studio — the frame chrome will be identical.

Where do my screenshots go?

Nowhere. There is no server, no account and no upload: the app is a static page, the image is held in memory, and the PNG is composed on your own canvas. Closing the tab clears it.

Is a 3× export upscaled?

No. The frame, the bezel, the island and the shadow are drawn as vectors at the export scale, so a 3× mockup gets a crisp 3× frame. Only the page image inside the screen is limited by the resolution of the screenshot you supplied.

Are these the manufacturers' official device images?

No. Each frame is an original vector interpretation built from the published screen dimensions, corner radii and hardware features. Device names and trademarks belong to their owners and are used here for identification only. InstaFrame is not affiliated with, or endorsed by, Apple, Samsung or Google.

Does it work offline?

Yes. There are no external requests at all — no CDN, no webfonts, no analytics. Open the page from a local file or any static host and every feature except clipboard access behaves the same.
